# Vektoripaja – viikko 41

## Vko 41 – Työkalut käyttöön: valmis kuutio

### Mitä tein ja miten?
Siirsin toteutussuunnitelman ohjaajan pushaamaan suunnitelma.md-tiedostoon. Tein siirron Github Copilotin avulla, jotta sain säilytettyä järkevän ja selkeän rakenteen joutumatta käyttämään paljoa aikaa jonka voi hyödyntää paremmin muihin asioihin.

Sen jälkeen tein virtuaaliympäristön ja varmistin, että valmis kuutiosovellus toimii.
Kaikki testit palauttivat "Ok" ja kuutio pyöri kuten pitää.

Kuutiosovelluksen testaamisen jölkeen tein Microsoft Copilotin ja GitHub Copilotin avulla UI testaussovelluksen.

### Miksi tein näin?
Tein näin. jotta minuulla on toimivat työkalut varsinaisen projektin aloittamista varten ja jotta pystyin testata käytännössä millaiset värit ja kokomääritykset ovat sopivat.
